# Miku Mood Images

Add your own Hatsune Miku images for each mood state. 
Recommended size: 200x200 pixels (square, PNG with transparency)

## Required files:
- `happy.png` - Smiling, positive Miku (greetings, good news)
- `excited.png` - Very enthusiastic Miku (recommending something amazing)
- `thinking.png` - Contemplative Miku (considering options)
- `teaching.png` - Explaining/pointing Miku (sharing knowledge)
- `love.png` - Hearts/blushing Miku (romantic suggestions)
- `surprised.png` - Shocked/amazed Miku (interesting facts)
- `confused.png` - Question mark/puzzled Miku (needs clarification)
- `neutral.png` - Default calm Miku (general responses)

## Where to find images:
- Safebooru: https://safebooru.org/index.php?page=post&s=list&tags=hatsune_miku+chibi
- Pixiv (search "初音ミク スタンプ")
- LINE Sticker packs (Miku stickers)
- DeviantArt (search "Miku emoji" or "Miku stickers")

## Important:
- Use images that are appropriate and legally shareable
- Chibi/sticker style works best for small avatars
- Make sure backgrounds are transparent or match app theme
